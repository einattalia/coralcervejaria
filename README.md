# Coral Cervejaria

Site estático em um único arquivo. Imagens, fonte, estilos e JavaScript estão incorporados ao index.html.

## Abrir localmente

Abra index.html no navegador.

## Subir no GitHub

Extraia o ZIP e adicione index.html e README.md à raiz do repositório. Para publicar pelo GitHub Pages, selecione a branch principal e a pasta raiz em Settings > Pages.

O carrinho monta uma consulta de pedido pelo Instagram. A calculadora funciona diretamente no navegador.
